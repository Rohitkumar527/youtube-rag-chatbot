# YouTube RAG Chatbot

A YouTube RAG Chatbot built using LangChain, Google Gemini, FAISS, Supadata and Streamlit.

## Features

- Load a YouTube video using its URL
- Extract video transcript
- Split transcript into chunks
- Generate embeddings
- Store embeddings using FAISS
- Retrieve relevant transcript context
- Ask questions about the video
- Get answers using Google Gemini
- Streamlit-based web interface

## Tech Stack

- Python
- LangChain
- Google Gemini
- FAISS
- Supadata
- Streamlit

## Project Files

- `app.py` - Streamlit web application
- `YouTube_chatbot_using_langchain.ipynb` - Original RAG pipeline developed in Google Colab
- `requirements.txt` - Required Python packages
